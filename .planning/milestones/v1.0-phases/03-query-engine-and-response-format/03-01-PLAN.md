    ```typescript
    import { Inject, Injectable, PipeTransform } from '@nestjs/common'
    import type { ArgumentMetadata } from '@nestjs/common'
    import { parseQuery } from '../parser/parser.js'
    import { EdmRegistry } from '../edm/edm-registry.js'
    import { ODATA_MODULE_OPTIONS } from '../tokens.js'
    import type { ODataModuleResolvedOptions } from '../odata.module.js'
    import type { ODataQuery } from './odata-query.types.js'
    import type { EdmEntityType } from '../edm/edm-entity-type.js'
    import type { FilterNode } from '../parser/ast.js'
    import { ODataValidationError } from './odata-validation.error.js'
    ```

    The pipe's `transform(value, metadata)` method:
    1. Receives `value` as `Record<string, string>` (req.query object from Express)
    2. Reconstructs a query string from the Record entries (joining with `&`)
    3. Calls `parseQuery(queryString)` to get `QueryOptions` (filter AST, select, orderBy, top, skip)
    4. Extracts `$count=true` from the raw value (parser doesn't handle $count yet — check for key `$count` with value `'true'`)
    5. Reads `entitySetName` from pipe data (passed by the `@ODataQuery(entitySetName)` param decorator)
    6. Looks up `EdmEntityType` from `EdmRegistry.getEntityType(entityTypeName)` where entityTypeName is derived from the entitySet
    7. Validates all property references in $filter (walk FilterNode, find PropertyAccessNode, check each path[0] against entityType.properties)
    8. Validates all $select items (each SelectItem.path[0] must exist in entityType.properties)
    9. Validates all $orderby expressions (walk each OrderByItem.expression for PropertyAccessNode)
    10. Enforces maxTop: if `top > options.maxTop`, clamp to `options.maxTop`
    11. Returns the typed `ODataQuery` object

    For field validation (D-10), create a private helper `validatePropertyReferences(entityType: EdmEntityType, nodes: FilterNode[])` that recursively walks FilterNode trees and throws `ODataValidationError` for any `PropertyAccessNode` whose `path[0]` is not in `entityType.properties.map(p => p.name)`.

    The pipe needs to be `@Injectable()` and inject `EdmRegistry` and `ODATA_MODULE_OPTIONS`.
