    **Create `packages/typeorm/src/translator/typeorm-auto-handler.ts`:**

    This is an `@Injectable()` class that the auto-handler machinery uses. It is NOT a controller itself — it is injected by the module and called by controllers.

    ```typescript
    import { Injectable } from '@nestjs/common'
    import type { Repository, SelectQueryBuilder } from 'typeorm'
    import type { ODataQuery, ODataQueryResult } from '@nestjs-odata/core'
    import type { EdmEntityType } from '@nestjs-odata/core'
    import { TypeOrmQueryTranslator } from './typeorm-query-translator.js'
    ```

    Constructor receives `TypeOrmQueryTranslator` and the request URL base for nextLink construction.

    **`handleGet(query: ODataQuery, requestUrl: string): Promise<ODataQueryResult>`:**
    1. Look up `EdmEntityType` from `EdmRegistry` using `query.entitySetName`
    2. Call `translator.translate(query, entityType)` to get `SelectQueryBuilder`
    3. Determine `effectiveTop = query.top ?? maxTop` (from module options)
    4. **nextLink detection (per Pitfall 2 and RESEARCH.md):** Modify the qb to `take(effectiveTop + 1)` to fetch one extra row
    5. Execute: if `query.count`, call `qb.getManyAndCount()`; else `qb.getMany()`
    6. Check `hasMore = items.length > effectiveTop`
    7. If hasMore: slice items to `effectiveTop`, build nextLink URL with `$skip` incremented
    8. If not hasMore: nextLink is undefined
    9. Return `{ items, count, nextLink, select: query.select }`

    **`handleCount(query: ODataQuery): Promise<number>`:**
    1. Build a stripped query: only `filter` and `entitySetName` — no top, skip, orderby, select (Pitfall 3)
    2. Call `translator.translate(strippedQuery, entityType)` to get qb
    3. Return `await qb.getCount()`

    **`buildNextLink(requestUrl: string, newSkip: number, top: number): string`:**
    Helper that rebuilds the URL with updated `$skip` and `$top` values. Parse the URL, update/add `$skip` param, ensure `$top` param is present.

| Threat ID | Category        | Component                   | Disposition | Mitigation Plan                                                                                                                                                     |

| T-03-12   | Tampering       | $count route                | mitigate    | handleCount strips $top/$skip/$orderby/$select before building count query. Only $filter applied. Prevents manipulation of count via pagination params (Pitfall 3). |
