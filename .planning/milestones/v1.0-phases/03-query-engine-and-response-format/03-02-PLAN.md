  <behavior>
    ## FilterVisitor (per D-01, D-02, D-04)
    - `Price gt 5` -> `qb.andWhere('entity.Price > :p1', { p1: 5 })` — comparison operators
    - `Name eq 'Widget'` -> `qb.andWhere('entity.Name = :p1', { p1: 'Widget' })` — string literal parameterized
    - `Price gt 5 and Active eq true` -> two andWhere calls with unique params :p1, :p2
    - `Price gt 5 or Price lt 1` -> uses Brackets with orWhere inside
    - `not Active eq true` -> `qb.andWhere('NOT (entity.Active = :p1)', { p1: true })`
    - `contains(Name,'widget')` -> `qb.andWhere('entity.Name LIKE :p1', { p1: '%widget%' })` (D-02)
    - `startswith(Name,'Wid')` -> `qb.andWhere('entity.Name LIKE :p1', { p1: 'Wid%' })`
    - `endswith(Name,'get')` -> `qb.andWhere('entity.Name LIKE :p1', { p1: '%get' })`
    - `contains(Name,'widget%special')` -> LIKE param escapes % to \% before wrapping: `'%widget\%special%'` (Pitfall 6)
    - `length(Name) gt 5` -> `qb.andWhere('LENGTH(entity.Name) > :p1', { p1: 5 })` — raw SQL function
    - All parameters use unique names :p1, :p2, :p3... — no collisions across complex filters
    - SECURITY: `.getQuery()` output contains `:p` placeholders and NO raw literal values

    ## SelectVisitor (per D-03)
    - `$select=Name,Price` -> `qb.select(['entity.Name', 'entity.Price'])` plus always includes key properties
    - `$select=*` or no select -> no qb.select() call (return all columns)
    - Key properties (e.g., Id) always included in selection even if not in $select

    ## OrderByVisitor (per D-04)
    - `$orderby=Name asc` -> `qb.orderBy('entity.Name', 'ASC')`
    - `$orderby=Price desc,Name asc` -> `qb.orderBy('entity.Price', 'DESC').addOrderBy('entity.Name', 'ASC')`

    ## PaginationVisitor (per D-05)
    - `$top=10&$skip=20` -> `qb.take(10).skip(20)`
    - No $top or $skip -> no take/skip calls
    - $top=0 -> `qb.take(0)` (valid — returns empty result)

    ## TypeOrmQueryTranslator
    - Orchestrates visitors in order: filter -> select -> orderby -> pagination (per RESEARCH.md)
    - translate() returns the SelectQueryBuilder (no DB call)
    - execute() with includeCount=false calls getMany()
    - execute() with includeCount=true calls getManyAndCount() and returns { items, count }

    - packages/core/src/query/odata-query.types.ts (ODataQuery, ODataQueryResult)

    **FilterVisitor (`TypeOrmFilterVisitor`):**

    Implements `FilterVisitor<void>` from `@nestjs-odata/core`. Constructor takes `(qb: SelectQueryBuilder<unknown>, alias: string, entityType: EdmEntityType)`. Maintains a private `paramCount = 0` for unique parameter names.

    Operator mapping for comparison ops:
    - `eq` -> `=`, `ne` -> `!=`, `lt` -> `<`, `le` -> `<=`, `gt` -> `>`, `ge` -> `>=`

    For logical ops (`and`, `or`):
    - `and`: recurse into left and right — both add via `andWhere`
    - `or`: use TypeORM `Brackets` — `qb.andWhere(new Brackets(sub => { visitLeft on sub; sub.orWhere(...visitRight) }))`

    String function mapping (D-02):
    - `contains(prop, val)` -> `LIKE '%val%'` with LIKE-escaped val (escape `%` -> `\%`, `_` -> `\_`)
    - `startswith(prop, val)` -> `LIKE 'val%'` with LIKE-escaped val
    - `endswith(prop, val)` -> `LIKE '%val'` with LIKE-escaped val
    - `length(prop)` -> `LENGTH(alias.prop)` (raw SQL)
    - `indexof(prop, val)` -> `INSTR(alias.prop, val)` (raw SQL, returns 0-based per OData spec — subtract 1)
    - `tolower(prop)` -> `LOWER(alias.prop)`
    - `toupper(prop)` -> `UPPER(alias.prop)`
    - `trim(prop)` -> `TRIM(alias.prop)`

    Property resolution: `resolveProperty(node: PropertyAccessNode)` returns `${alias}.${node.path[0]}`. Verify against entityType.properties — this validation already happened in the pipe, but defense-in-depth.

    Literal extraction: `extractLiteral(node: LiteralNode)` returns `node.value` directly (TypeORM handles type coercion).

    **SelectVisitor (`TypeOrmSelectVisitor`):**

    Constructor takes `(qb: SelectQueryBuilder<unknown>, alias: string, entityType: EdmEntityType)`.

    `apply(select: SelectNode)`:
    - If `select.all` is true or `select.items` is undefined/empty, do nothing (return all columns)
    - Otherwise, build `columns = select.items.map(item => \`${alias}.${item.path[0]}\`)`
    - Always add key properties: `entityType.keyProperties.forEach(k => columns.push(\`${alias}.${k}\`))`
    - Deduplicate columns
    - Call `qb.select(columns)`

    **OrderByVisitor (`TypeOrmOrderByVisitor`):**

    Constructor takes `(qb: SelectQueryBuilder<unknown>, alias: string)`.

    `apply(orderByItems: OrderByItem[])`:
    - For the first item: `qb.orderBy(\`${alias}.${propertyName}\`, direction.toUpperCase())`
    - For subsequent items: `qb.addOrderBy(\`${alias}.${propertyName}\`, direction.toUpperCase())`

    Extract property name from `OrderByItem.expression` — it should be a `PropertyAccessNode` (path[0]).

    **PaginationVisitor (`TypeOrmPaginationVisitor`):**

    Constructor takes `(qb: SelectQueryBuilder<unknown>)`.

    `apply(top?: number, skip?: number)`:
    - If `top !== undefined`: `qb.take(top)`
    - If `skip !== undefined`: `qb.skip(skip)`

    **TypeOrmQueryTranslator:**

    `@Injectable()` class implementing `IQueryTranslator<SelectQueryBuilder<unknown>>`.

    Constructor injects the TypeORM `Repository` (or `DataSource`) and receives `EntityMetadata` for column name resolution. The exact injection mechanism is Claude's discretion — the recommended approach is to receive `Repository<unknown>` and call `repo.createQueryBuilder(alias)`.

    `translate(query: ODataQuery, entityType: EdmEntityType): SelectQueryBuilder<unknown>`:
    1. `const alias = 'entity'`
    2. `const qb = this.repo.createQueryBuilder(alias)`
    3. If `query.filter`: `new TypeOrmFilterVisitor(qb, alias, entityType).visit(query.filter)` (using acceptVisitor)
    4. If `query.select`: `new TypeOrmSelectVisitor(qb, alias, entityType).apply(query.select)`
    5. If `query.orderBy?.length`: `new TypeOrmOrderByVisitor(qb, alias).apply(query.orderBy)`
    6. `new TypeOrmPaginationVisitor(qb).apply(query.top, query.skip)`
    7. Return `qb`

    `execute(qb: SelectQueryBuilder<unknown>, includeCount: boolean): Promise<ODataQueryResult>`:
    - If `includeCount`: `const [items, count] = await qb.getManyAndCount(); return { items, count }`
    - Else: `const items = await qb.getMany(); return { items }`
