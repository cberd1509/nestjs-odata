    - `@Injectable()` class `CsdlBuilder`
    - Constructor injects `EdmRegistry` and `@Inject(ODATA_MODULE_OPTIONS) options: ODataModuleOptions`
    - `buildCsdlXml(): string` — builds and caches the full EDMX XML string
    - Private `cachedXml: string | null = null` — built once, returned on subsequent calls (per D-17)
    - XML structure (per OASIS spec and RESEARCH.md Pattern 4):
      ```xml
      <?xml version="1.0" encoding="UTF-8"?>
      <edmx:Edmx xmlns:edmx="http://docs.oasis-open.org/odata/ns/edmx" Version="4.0">
        <edmx:DataServices>
          <Schema xmlns="http://docs.oasis-open.org/odata/ns/edm" Namespace="{namespace}">
            <!-- EntityType elements -->
            <EntityType Name="{name}">
              <Key>
                <PropertyRef Name="{keyProp}"/>
              </Key>
              <Property Name="{name}" Type="{edmType}" Nullable="{true|false}" [Precision="N"] [Scale="N"]/>
              <NavigationProperty Name="{name}" Type="{namespace.Target|Collection(namespace.Target)}" [Nullable="{true|false}"]/>
            </EntityType>
            <!-- EntityContainer -->
            <EntityContainer Name="Container">
              <EntitySet Name="{setName}" EntityType="{namespace}.{typeName}"/>
            </EntityContainer>
          </Schema>
        </edmx:DataServices>
      </edmx:Edmx>
      ```
    - Use method-based string builder (NOT template literals for the XML body). Build each element via helper methods: `buildEntityTypeXml(et)`, `buildPropertyXml(prop)`, `buildNavigationPropertyXml(nav)`, `buildEntitySetXml(es)`.
    - Namespace defaults to `'Default'` (per D-08). Container name is `'Container'` (per D-09).

    **Wire TypeOrmEdmDeriver into ODataTypeOrmModule** (per D-06, D-16, EDM-06):

    **packages/typeorm/src/odata-typeorm.module.ts — update:**
    - Add `TypeOrmEdmDeriver` import from `./deriver/typeorm-edm-deriver.js`
    - Create an `@Injectable()` class `TypeOrmEdmInitializer` that implements `OnModuleInit`:
      ```typescript
      @Injectable()
      export class TypeOrmEdmInitializer implements OnModuleInit {
        constructor(
          private readonly dataSource: DataSource,
          private readonly edmRegistry: EdmRegistry,
          @Inject(ODATA_MODULE_OPTIONS) private readonly options: ODataModuleOptions,
          @Inject(TYPEORM_ODATA_ENTITIES) private readonly entityClasses: Function[],
        ) {}

        onModuleInit(): void {
          const deriver = new TypeOrmEdmDeriver(
            this.options.namespace ?? 'Default',
            this.options.unmappedTypeStrategy ?? 'skip',
          )
          const metadatas = this.entityClasses.map(cls => this.dataSource.getMetadata(cls))
          const configs = deriver.deriveEntityTypes(this.entityClasses, metadatas)
          for (const config of configs) {
            const entityType: EdmEntityType = {
              name: config.entityTypeName,
              namespace: this.options.namespace ?? 'Default',
              properties: config.properties,
              navigationProperties: config.navigationProperties,
              keyProperties: config.keyProperties,
              isReadOnly: config.isReadOnly,
            }
            const entitySet: EdmEntitySet = {
              name: config.entitySetName,
              entityTypeName: config.entityTypeName,
              namespace: this.options.namespace ?? 'Default',
              isReadOnly: config.isReadOnly,
            }
            this.edmRegistry.register(entityType, entitySet)
          }
        }
      }
      ```
    - Add `TypeOrmEdmInitializer` to `forFeature()` providers array
    - Export `TypeOrmEdmInitializer` and `TypeOrmEdmDeriver` from `packages/typeorm/src/index.ts`
