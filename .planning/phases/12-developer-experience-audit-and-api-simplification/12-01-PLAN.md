<objective>
Simplify the controller registration, query pipe wiring, and serviceRoot inheritance patterns
to eliminate boilerplate that developers currently must write.

Purpose: Remove three sources of API friction identified during docs review:

1. Dual controller registration (forRoot controllers array + @Module controllers)
2. Manual @UsePipes(ODataQueryPipe) coupling on every query method
3. Redundant serviceRoot parameter in forFeature()

Output: Simplified module/decorator APIs with zero-boilerplate controller registration,
auto-applied query pipe, and inherited serviceRoot. All existing e2e tests pass.
</objective>

      resolve it from DI automatically.

      const RawQuery = createParamDecorator((data: string | undefined, ctx: ExecutionContext) => {
