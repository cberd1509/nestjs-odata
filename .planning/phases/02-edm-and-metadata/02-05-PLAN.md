   - Import `reflect-metadata` at the top (same as existing e2e tests).
   - Use the same NestJS test module setup pattern from `metadata.e2e-spec.ts`: create AppModule, init app, create supertest instance.
   - In a single test case named "odata2ts validates $metadata CSDL XML without errors":

c. Run odata2ts against the temp file using `node:child_process` `execSync`:

     ```
     execSync(`npx odata2ts -s ${tmpFilePath} -o ${tmpOutputDir}`, {
       cwd: process.cwd(),
       timeout: 30000,
       encoding: 'utf-8'
     })
     ```

     Use a temp output directory (also in `os.tmpdir()`).
     d. If `execSync` throws, the test fails (odata2ts returned non-zero exit code = validation error).
     e. Assert the test reached this point (odata2ts exited 0).
     f. Clean up: remove the temp file and temp output directory in an `afterAll` or `finally` block using `fs.rmSync` with `{ recursive: true, force: true }`.

   - Use `beforeAll` / `afterAll` for app lifecycle (same pattern as existing e2e test).
   - Set the Vitest test timeout to 60000ms (odata2ts generation can be slow on first run) using `{ timeout: 60000 }` in the `describe` or `it` block.

3. Verify: Run `pnpm --filter @nestjs-odata/core build && pnpm --filter @nestjs-odata/typeorm build && pnpm --filter test-app test` and confirm the new test passes.
