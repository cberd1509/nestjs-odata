    - Export class `TypeOrmEdmDeriver` implementing `IEdmDeriver`

    - `deriveEntityTypes(entityClasses: Function[], entityMetadatas: EntityMetadata[]): EdmEntityConfig[]` — accepts both the original classes (for decorator reads) and their TypeORM metadata
    - For each entity:
      1. Get `EntityMetadata` for the class from the provided array
      2. Read `@ODataExclude()` overrides via `getExcludedProperties(entityClass)`

      4. Read `@ODataEntitySet()` override via `getEntitySetName(entityClass)`
      5. Map columns: for each `ColumnMetadata` not in excluded set:
         - Check `@EdmType()` override first
         - Otherwise call `mapColumnTypeToEdm(col.type as string, col.propertyName === '...' ? ... : undefined, this.unmappedTypeStrategy)`
         - Build `EdmProperty` with `name`, `type`, `nullable: col.isNullable`, `precision: col.precision`, `scale: col.scale`
      6. Map relations: for each `RelationMetadata`:
         - `name: rel.propertyName`
         - `type: isCollection ? 'Collection(${namespace}.${target})' : '${namespace}.${target}'`

      8. Detect `@ViewEntity`: check `meta.tableType === 'view'` → `isReadOnly: true`
