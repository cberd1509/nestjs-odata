  <action>
1. Install root devDependencies (per D-08, D-09, D-10):
   ```bash
   pnpm add -D -w eslint typescript-eslint eslint-config-prettier prettier husky lint-staged @commitlint/cli @commitlint/config-conventional @changesets/cli @changesets/changelog-github
   ```

2. Create `packages/eslint-config/package.json`:
   ```json
   {
     "name": "@repo/eslint-config",
     "version": "0.0.0",
     "private": true,
     "type": "module",
     "exports": {
       ".": "./eslint.config.mjs"
     },
     "dependencies": {
       "@eslint/js": "^9.0.0",
       "typescript-eslint": "^8.0.0",
       "eslint-config-prettier": "^10.0.0"
     }
   }
   ```

3. Create `packages/eslint-config/eslint.config.mjs`:
   ```javascript
   import eslint from '@eslint/js'
   import tseslint from 'typescript-eslint'
   import prettierConfig from 'eslint-config-prettier'

   export default tseslint.config(
     { ignores: ['**/dist/**', '**/node_modules/**', '**/coverage/**', '**/*.js', '**/*.cjs', '**/*.mjs'] },
     eslint.configs.recommended,
     ...tseslint.configs.recommendedTypeChecked,
     prettierConfig,
     {
       languageOptions: {
         parserOptions: { projectService: true },
       },
       rules: {
         '@typescript-eslint/no-explicit-any': 'off',
         '@typescript-eslint/no-unsafe-assignment': 'off',
       },
     },
   )
   ```
   Note: Do NOT use eslint-plugin-prettier (causes double errors per research anti-patterns). Use eslint-config-prettier to disable conflicting rules, run Prettier separately.

4. Create root `eslint.config.mjs`:
   ```javascript
   import config from '@repo/eslint-config'
   export default config
   ```

5. Create `.prettierrc`:
   ```json
   {
     "semi": false,
     "singleQuote": true,
     "trailingComma": "all",
     "printWidth": 100,
     "tabWidth": 2
   }
   ```

6. Create `.prettierignore`:
   ```
   dist
   node_modules
   coverage
   .changeset
   pnpm-lock.yaml
   ```

7. Create `commitlint.config.cjs`:
   ```javascript
   module.exports = {
     extends: ['@commitlint/config-conventional'],
   }
   ```
   Note: Use .cjs extension — commitlint does not support ESM config natively.

8. Create `lint-staged.config.mjs`:
   ```javascript
   export default {
     '*.{ts,tsx,js,mjs,cjs}': ['eslint --fix', 'prettier --write'],
     '*.{json,md,yml,yaml}': ['prettier --write'],
   }
   ```

9. Initialize Husky: `pnpm exec husky init`
   This creates `.husky/` directory. Then write hook files:

   `.husky/pre-commit`:
   ```bash
   pnpm exec lint-staged
   ```

   `.husky/commit-msg`:
   ```bash
   pnpm exec commitlint --edit $1
   ```

10. Update root package.json `scripts.prepare` to `"husky"` (replaces the placeholder from Plan 01).

11. Initialize Changesets: `pnpm exec changeset init`
    Then overwrite `.changeset/config.json` with:
    ```json
    {
      "$schema": "https://unpkg.com/@changesets/config/schema.json",
      "changelog": ["@changesets/changelog-github", { "repo": "your-org/nestjs-odata" }],
      "commit": false,
      "fixed": [],
      "linked": [],
      "access": "public",
      "baseBranch": "main",
      "updateInternalDependencies": "patch",
      "ignore": ["test-app"]
    }
    ```
    The `repo` field value can use the actual GitHub repo URL once established; for now use a placeholder org.

12. Run `pnpm install` to install new dependencies and link @repo/eslint-config.

13. Run `pnpm lint` to verify ESLint flat config works across all packages. Fix any lint errors in existing files (likely the placeholder index.ts files).
