**Create new `docs/guide/filter-functions.md`:**

This is the primary new content for Phase 7 coverage. Structure:

```markdown
# Filter Functions

Advanced filter operations including lambda expressions, arithmetic operators, date/time functions, and string functions.

## Lambda Expressions

### any()

Filter collections where at least one element matches.

\`\`\`
GET /Orders?$filter=Items/any(i: i/Price gt 100)
\`\`\`

Translates to SQL EXISTS subquery. Read `filter-visitor.ts` to get exact supported syntax.

### all()

Filter collections where every element matches.

\`\`\`
GET /Orders?$filter=Items/all(i: i/Shipped eq true)
\`\`\`

Translates to SQL NOT EXISTS with negated predicate.

## Arithmetic Operators

`add`, `sub`, `mul`, `div`, `mod` operators in filter expressions.

\`\`\`
GET /Products?$filter=Price add Tax gt 50
GET /Products?$filter=Price mul Quantity gt 1000
\`\`\`

## Date/Time Functions

`year()`, `month()`, `day()`, `hour()`, `minute()`, `second()` extraction functions.

\`\`\`
GET /Products?$filter=year(CreatedAt) eq 2024
GET /Orders?$filter=month(OrderDate) eq 12
\`\`\`

## String Functions

`contains()`, `startswith()`, `endswith()` (already supported), plus Phase 7 additions: `indexof()`, `substring()`, `concat()`.

\`\`\`
GET /Products?$filter=indexof(Name,'Pro') ge 0
GET /Products?$filter=substring(Name,0,3) eq 'Pro'
GET /Products?$filter=concat(FirstName,' ',LastName) eq 'John Doe'
\`\`\`
```

Read the actual `filter-visitor.ts` implementation to get the exact supported function names, parameter order, and SQL translations. Every example in this guide must use syntax that the visitor actually supports.
